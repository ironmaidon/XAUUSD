# Changelog

All notable source changes are recorded here. This strategy follows semantic versioning.

## 1.0.0 - Production Release Candidate

- Completed M12 static integration, non-repaint, state-ownership, order/risk, alert, and drawing-resource audits.
- Bounded qualified-setup score labels to reusable directional labels.
- Added non-trading release configuration diagnostics to the Detailed dashboard.
- Added release, architecture, and manual validation documentation.
- No signal, scoring, risk, order, target, breakeven, trailing, or alert-priority behavior was intentionally changed.
- Manual TradingView compilation, Strategy Tester validation, replay review, and realtime alert testing remain required.

## 0.11.0
